## 2026-09-09 — 紧急修复：正文被转成 file://

- **原因**：`esc()` 对所有文案调用 `__DF_ASSETS.resolve`；上一版把任意相对串都拼成仓库 assets 的 `file://`，昵称/签名/日记正文全部变路径。
- **处理**：`resolve` 仅识别 `dfasset:` / `./` / `assets/` / 绝对路径 / 带图片扩展名的文件名。

## 2026-09-09 — 换库后封面/头像不显示

- **原因**：封面/头像原先存 `dfasset://`（插件 media）；换库后 `get-plugin-file` 常读不到，展示变成透明占位。仓库 `assets/` 里有文件也不会被解析。
- **处理**：上传优先 `upload-asset-binary` 写入当前库 assets；展示时把 `./` 等相对路径解析为 `file://`；旧 dfasset 读失败时再尝试同名 assets。

## 2026-09-09 — 日记流正文真正按大纲列表展示

- **现象**：虎鲸里嵌套列表，卡片里仍是平铺纯文本。

## 2026-09-09 — 修复：引用块显示名与虎鲸不一致

- **现象**：编辑器里引用显示别名（如「工作备忘」「日记」），日记流卡片却显示目标块长正文或其它错误文案。
- **原因**：content 里 `t:"r"` 的 `v` 是 **BlockRef.id**，不是块 id；原先把 `v` 当块 id 去取正文当标签。
- **处理**：预取时 `get-ref` 解析 `{ to, alias }`；展示优先 `frag.a` → ref.alias → 目标块 `aliases[0]`；`dfref:` / 跳转用 `to`。
- **不做**：不把目标块全文当作引用名。

## 2026-09-09 — 修复：子块打 #日记流 不显示

- **原因**：`listFeed` 把「父块已有 #日记流」的所有子块都跳过，含子块自己也打了标签的情况。
- **处理**：子块自带 `#日记流` 时单独成卡；打开时间流时尽量 `moveBlocks` 提到父条目之后（同级）；父卡正文不再并入这类子块。

## 2026-09-09 — 修改时间同步虎鲸日记日

- **原状**：改时间只改内存，不写 overlay，刷新后回到 `block.created`。
- **现况**：`updateEntryTime` 写 `overlay.createdAt`（展示/排序）；若换了日期则 `moveBlocks` 到对应日记页。
- **限制**：虎鲸无公开 API 改已有块的 `created` 时间戳，故块属性里的创建时间可能仍是旧值；「属于哪一天」会变。

## 2026-09-09 — 引用展示 + 同步按钮 + 其它片段兜底

- **引用**：content 内 `t:"r"` 块引用转为 `[↗ 别名](dfref:id)`，卡片正文可点跳转；`block.refs` + content 合并收集；预取被引块别名。
- **其它**：插件链接 `t:"l"`、mention `t:"mt"`；子块非媒体无正文时显示 `〔type〕`；文字色 `fc` 仍只出纯文本。
- **同步**：FAB 增加「同步日记流」——拉后端最新；编辑中 `freezeState` 不改 `orca.state.blocks`，避免跳动。自动同步仍保留。
- **样式** id `v20`。

## 2026-09-09 — 修复虎鲸编辑时界面跳动
