# 日记流（orca-diaryflow）

虎鲸笔记（Orca Note）插件：朋友圈式日记时间流。

## 功能

- 时间线展示带 `#日记流` 标签的日记块（分页加载，底部「加载更多」）
- 封面 / 头像 / 签名设置
- 标签筛选、置顶、地点（写入正文末行 `地点：XXX`）
- 月份大纲（年份定位 + 分月跳转，对齐安卓版）
- 评论写入该条目下的虎鲸子块（日记页可见、可备份）
- 删除进回收站（约 30 天可恢复；入口在工具）
- 归档（主时间线隐藏、日记页保留；入口在工具）
- 工具：归档柜、回收站、搜索、统计、导出 Markdown/按月 zip/JSON、回顾、布局预设
- 快捷筛选：有图 / 有地点 / 仅置顶；「⋯」可管理图片（进度、重试、排序）
- 新建与正文编辑一律跳转虎鲸日记页（时间线不扁改正文）
- 设置：每页条目数、回收站保留天数、删除前确认（虎鲸「插件设置」中调整）
- 界面中英双语：跟随虎鲸语言设置（`orca.state.locale`）自动切换
- 筛选持久化：标签/关键词/快捷筛选（有图/有地点/仅置顶）重开面板后保留
- 评论可编辑：条目评论支持内联编辑（写入对应虎鲸子块）
- 封面日历随语言本地化（月份/年份/提示/照片·热力切换）
- 回收站与归档柜支持关键词搜索；导出文件名/内容随语言（`DiaryFlow_*`）
- 设置页标签随虎鲸语言切换即时刷新
- 时间线增量缓存：块与评论未变时复用上次结果，降低同步开销
- 导出 Word（.doc，图片尽力内嵌）；回收站/归档柜分页；归档柜一键全部取消归档
- 回收站一键全部恢复；工具「清理图片」移除未被引用的插件图片
- 上传封面/头像的报错文案随语言（暂不支持/SVG/尺寸/过大/转码失败等）
- 搜索支持「关键词 + 标签 + 快捷筛选 + 日期范围」组合；导出支持「打印 / 另存为 PDF」
- 面板内快速撰写（文字 / 图片 / 标签 / 时间 / 心情天气）
- 心情·天气字段（存块属性，时间线 chip 展示，可搜索）；卡片可编辑
- 备份与恢复：手动 + 可选每日自动备份（保留 N 份），支持从 JSON 文件导入
- 点封面日历的某天可跳转；无条目时打开当天日记；图片管理支持拖拽排序
- CI 在构建后运行 harness 测试（md-frag / i18n-filter / blocks-fusion / run-test）

## 安装

1. 从 [Releases](https://github.com/kx1356/orca-diaryflow/releases) 下载 zip
2. 解压到虎鲸 `plugins` 目录（如 `Documents/orca/plugins/`）
3. 重启虎鲸并在设置中启用「日记流」
4. 打开日记流面板：会把置顶「使用说明」写入今日日记顶部（手动删除后不再自动出现）

## 开发

```bash
node build.mjs
node tools/deploy.mjs
```
