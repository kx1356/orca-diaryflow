# 日记流（orca-diaryflow）

虎鲸笔记（Orca Note）插件：朋友圈式日记时间流。

## 功能

- 时间线展示带 `#日记流` 标签的日记块（分页加载，底部「加载更多」）
- 封面 / 头像 / 签名设置
- 标签筛选、置顶、地点（写入正文末行 `地点：XXX`）
- 月份大纲（年份定位 + 分月跳转，对齐安卓版）
- 评论写入该条目下的虎鲸子块（日记页可见、可备份）
- 删除进回收站（约 30 天可恢复；入口在工具）
- 归档（主时间线隐藏、日记页保留；入口在工具）
- 工具：归档柜、回收站、搜索、统计、导出 Markdown/按月 zip/JSON、回顾、布局预设
- 快捷筛选：有图 / 有地点 / 仅置顶；「⋯」可管理图片（进度、重试、排序）
- 新建与正文编辑一律跳转虎鲸日记页（时间线不扁改正文）

## 安装

1. 从 [Releases](https://github.com/kx1356/orca-diaryflow/releases) 下载 zip
2. 解压到虎鲸 `plugins` 目录（如 `Documents/orca/plugins/`）
3. 重启虎鲸并在设置中启用「日记流」
4. 打开日记流面板：会把置顶「使用说明」写入今日日记顶部（手动删除后不再自动出现）

## 开发

```bash
node build.mjs
node tools/deploy.mjs
```
